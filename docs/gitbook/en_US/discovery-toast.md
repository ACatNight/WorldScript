# Toast & Discovery

Discovery prompts show feedback when a player first enters or unlocks a region.

## Supported Feedback

- Title
- Subtitle
- Native advancement-style Toast
- Sound
- First-discovery reward actions

## In-Game Editing

```text
/ws edit <region-id> discovery
```

You can edit:

- Discovery toggle
- Title toggle
- Toast toggle
- Toast title and description
- Toast icon
- Toast frame
- First-discovery reward actions

## Test Toast

```text
/ws toast test <region-id>
```

If it does not appear:

```text
/ws toast diagnose <region-id>
```

Check the icon item, server version, and whether Toast is enabled.
