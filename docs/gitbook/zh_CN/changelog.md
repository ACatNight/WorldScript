# 更新记录

## 1.0.0

WorldScript 1.0.0 增加了以下区域玩法：

- 多边形区域，可沿道路、山谷和其他不规则地形设置边界。
- 原生成就样式的发现 Toast，以及编辑、预览和诊断指令。
- 按区域刷原版怪或 MythicMobs 怪，支持附近玩家判断和存活上限。
- 基于 `peaceful`、`dangerous` 状态的 PVP 保护，边界两侧的玩家都会检查。
- 内置模块状态和可选的外置模块 API；外置模块加载默认关闭。
- 更完整的发现动作、进入条件、编辑器反馈和中英文文档。

这一版还修正了重复进入判定、取消或改向移动后误触发效果、满背包奖励丢失、菜单 Shift 点击丢物品等问题。区域编辑会保留原文件名，删除区域时清理重复定义。刷怪重载保留存活计数，禁用规则时清理其怪物；区块未加载时延后清理。外置模块会检查依赖是否成功启用。

最新的 1.0.0 JAR 还修复了 Paper 1.21.8 上反复出现的 `ChunkUnloadEvent` 报错。

升级后建议做三件事：

1. 执行 `/ws validate` 看区域配置有没有旧问题。
2. 执行 `/ws modules list` 看模块状态。
3. 如果用了刷怪，执行 `/ws spawn test <规则ID>` 单独测一次。
4. 如果主城要禁 PVP，站在主城里执行 `/ws protect test` 看一眼结果。
