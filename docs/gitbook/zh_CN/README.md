# WorldScript

WorldScript 是一个面向 Paper 1.12.2 至 1.21.8 的区域脚本插件，用来制作地图区域、区域事件、发现提示、玩家区域进度和区域附属玩法。

它适合 RPG、开放世界、剧情服、探索服和活动地图。任务流程可以交给 Chemdah 等任务插件，WorldScript 负责“玩家在哪里、触发了什么、这个区域现在是什么状态”。

## 核心能力

- 普通立方体区域与多边形区域
- 父子区域、继承变量和区域状态
- 进入、离开、左键、右键和交互事件
- 条件判断、动作列表、Kether 脚本
- 首次发现 Title、Toast、音效和奖励动作
- 聊天栏编辑器与 GUI 选择
- PlaceholderAPI 变量
- `modules/*.jar` 模块目录与受保护外置模块加载
- Spawn 模块：绑定区域随机刷怪，支持 MythicMobs 怪物库点选
