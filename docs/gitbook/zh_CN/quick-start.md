# 快速开始

这一页带你用最少步骤创建第一个区域。

## 1. 获取选区工具

```text
/ws wand
```

左键选择第一个角点，右键选择第二个角点。

## 2. 创建区域

```text
/ws create starter_valley 初始山谷
```

`starter_valley` 是内部区域 ID，`初始山谷` 是玩家看到的显示名称。

## 3. 打开编辑器

```text
/ws edit starter_valley
```

聊天栏编辑器会显示区域信息、事件、发现提示、粒子、多边形、刷怪等入口。

## 4. 测试区域

```text
/ws validate starter_valley
/ws test starter_valley
```

如果没有报错，就可以进入区域测试事件、Toast、粒子和刷怪。
