# 编辑器

WorldScript 的编辑器是给服主管理用的，目标就是少写配置、少记格式。

## 聊天栏编辑器

```text
/ws edit <区域ID>
```

常用页面：

- `main`：名字、角色、父区域这些基础信息
- `events`：进入、离开、点击事件
- `discovery`：首次发现提示、Toast、奖励
- `conditions`：进入条件
- `spawn`：刷怪规则
- `data`：变量和状态

## 怎么用比较舒服？

先点按钮改，不行再写 YAML。

一般顺序：

1. 先建区域
2. 打开编辑器
3. 改显示名、父区域、条件
4. 加事件或发现提示
5. `/ws validate`
6. 进服实测

## GUI 点选

这些东西更适合 GUI：

- Toast 图标
- MythicMobs 怪物
- 区域列表

能点就点，少手打 ID，出错概率会低很多。
