# Spawn 怪物刷新

Spawn 模块就是做“这个区域刷什么怪”。

比如玩家靠近狼王洞穴，就在洞穴范围内随机刷狼；玩家离太远，就不刷，省性能。

## 最简单的做法

```text
/ws edit <区域ID> spawn
```

然后点：

```text
[+ 选择怪物]
```

如果服务器装了 MythicMobs，GUI 里会显示 MM 怪物库。你点哪个怪，就用哪个怪物 ID。

创建完规则以后，再回聊天栏编辑：

- 一次刷几只
- 多久刷一次
- 最多活几只
- 玩家靠多近才刷
- 是否随机找安全位置

## 测试

```text
/ws spawn test <规则ID>
```

这条指令很重要。它能帮你区分是“规则没生效”，还是“区域里找不到安全落点”，还是“MM 怪物 ID 不存在”。

## 常用参数

- 区域 ID：怪刷在哪个区域
- 怪物 ID：MythicMobs ID 或原版实体类型
- 每次数量：默认随机 1 到 3
- 最大存活：默认最多 10
- 玩家检测范围：附近有玩家才刷
- 随机刷新：在区域内随机找安全点

## 小建议

普通野外区域别刷太密。先少量、低频、有限制，确认没卡服再加。
