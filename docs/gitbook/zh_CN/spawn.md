# Spawn 怪物刷新

Spawn 模块用于给区域绑定刷怪规则。玩家靠近区域时，插件会在区域内随机寻找安全位置生成怪物。

## 最简单流程

```text
/ws edit <区域ID> spawn
```

然后：

1. 点击 `[+ 选择怪物]`。
2. 在 GUI 中选择 MythicMobs 怪物。
3. 自动创建绑定当前区域的刷怪规则。
4. 回到聊天栏编辑器调整数量、间隔、最大存活和玩家检测范围。
5. 执行测试。

```text
/ws spawn test <规则ID>
```

## 常用参数

- 区域 ID：怪物在哪个区域刷。
- 怪物 ID：MythicMobs ID 或原版实体类型。
- 每次数量：默认随机 1 到 3。
- 最大存活：默认最多 10。
- 玩家检测范围：附近有玩家才刷新。
- 随机刷新：在区域内随机找安全点。

## MythicMobs

安装 MythicMobs 后，GUI 会读取 MM 怪物库。点击怪物即可创建或切换规则怪物 ID。
