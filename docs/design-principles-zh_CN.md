# WorldScript 设计原则

WorldScript 是开放世界 RPG 的区域编排层。它负责把地图空间、玩家状态和外部内容连接起来，不负责替代任务、等级、声望或战斗插件。

## 功能边界

WorldScript 负责：

- 区域范围、父子关系和继承
- 区域状态、进入/离开/交互触发
- 玩家区域解锁、进入和完成状态
- 变量、条件、动作、奖励和粒子氛围
- PlaceholderAPI 变量和外部插件回写

WorldScript 不负责：

- 任务定义、任务步骤和对话树
- 等级、声望、职业和战斗数值
- 地图可视化绘制工具

## 配置原则

区域 ID 用于配置和插件调用，名称用于玩家看到的内容。父区域适合放通用环境和规则，关键剧情放在具体子区域中。简单动作优先使用内置动作，复杂流程再使用 Kether。

每个区域尽量承担一个主要空间职责：据点、普通探索区、兴趣点、危险区或入口。开放世界不应该把所有地点排成一条必经路线。

## 编辑体验

/ws gui 是快速区域列表：左键传送，右键进入聊天编辑器。区域的详细配置仍以 YAML 和聊天编辑器为准，避免维护两套互相冲突的配置界面。

编辑器新增功能时应满足：旧配置可读取、结果可验证、操作有反馈、复杂能力有明确边界。
