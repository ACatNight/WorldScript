# README artwork

- `logo.png`: the project's selected W logo, copied from the supplied brand asset.
- `regions.svg`, `events.svg`, `progress.svg`, `spawn.svg`, `protect.svg`, `editor.svg`: small feature icons.

Icons use a 32 × 32 view box, teal strokes and transparent backgrounds. Both language READMEs use the same local assets. Feature names are provided as adjacent text so the icons are decorative.

These assets were prepared with AI-assisted design and code. This directory does not imply acceptance under any third-party marketplace's artwork policy.
