# Publishing material

The public README is an introduction to the project. Detailed setup instructions live in [GitBook](../gitbook/README.md).

Existing resource-page drafts:

- [Modrinth copy](../modrinth-description.md)
- [SpigotMC copy](../spigot-description.md)

Treat these as drafts and check commands, versions and screenshots before publishing. The root [changelog](../../CHANGELOG.md) is the release-history source.

Generated previews, upload templates, media ZIPs, cover variations and design experiments are kept locally and ignored by Git. Existing files are preserved in place so their local previews and generators continue to resolve.

Selected artwork intended for GitHub lives in [assets/readme](../assets/readme/README.md). Do not commit third-party plugin JARs, API credentials or server data with publishing material.
